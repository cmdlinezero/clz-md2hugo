# clz-md2hugo v0.4.2

## Hugo-aware generated-file ownership

Generated Hugo content now preserves YAML (`---`) and TOML (`+++`) front matter at byte zero. The generator ownership marker is inserted immediately after front matter, allowing Hugo to parse generated pages normally while retaining safe stale-file cleanup.

Ownership detection remains backward compatible with files generated by v0.4.0 and v0.4.1, where the marker appeared as the first line. Human-authored files without the marker remain untouched.

## Validation

The generator test suite covers YAML and TOML marker placement, legacy marker detection, human-owned content preservation, stale cleanup, and `--check` behaviour.

git tag -a v0.4.2 -m "Make generated-file ownership Hugo-aware"
